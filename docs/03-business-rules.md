# Бизнес-правила — Dozor Engine

**Версия:** 0.4  
**Статус:** черновик; не все правила детализированы

| ID | Правило | Статус |
|---|---|---|
| BR-01 | Задание может содержать основные и бонусные игровые коды. | Согласовано; точная кардинальность требует уточнения |
| BR-02 | Оценка сложности задания необязательна. | Согласовано |
| BR-03 | Оценка опасности задания необязательна. | Согласовано |
| BR-04 | Организатор вручную определяет последовательность заданий для каждой команды. | Согласовано |
| BR-05 | Игровой пакет конкретной команды формируется на основе заданий игры и назначенного ей маршрута. | Согласовано на концептуальном уровне |
| BR-06 | Задания создаются в рамках одной игры и не переиспользуются в других играх; общей библиотеки заданий нет. | Согласовано |
| BR-07 | Одно задание в рамках игры может входить в маршруты разных команд под разными порядковыми номерами. | Согласовано |

| BR-08 | Первое задание доступно после ввода корректного единого стартового кода, объявляемого организатором. | Согласовано |
| BR-09 | При старте открывается первое задание индивидуального маршрута команды. | Согласовано |
| BR-10 | Оценка сложности отображается только при наличии заданного значения. | Согласовано |
| BR-11 | Оценка опасности отображается только при наличии заданного значения. | Согласовано |

| BR-12 | После нахождения всех основных кодов прогресс основных кодов достигает 100%. | Согласовано |
| BR-13 | Переход к следующему заданию становится доступным только после нахождения всех основных кодов при обычном прохождении. | Согласовано |
| BR-14 | Нахождение всех основных кодов не вызывает автоматический переход к следующему заданию. | Согласовано |
| BR-15 | После нахождения всех основных кодов команда может продолжать вводить бонусные коды текущего задания. | Согласовано |
| BR-16 | Переход к следующему заданию происходит после явного действия представителя команды. | Согласовано |

| BR-17 | При выборе действия «Следующее задание» команда окончательно завершает текущее задание; вернуться к вводу его кодов, включая бонусные, нельзя. | Согласовано |

## Неопределённые правила (не утверждены)

| ID | Вопрос |
|---|---|
| OQ-01 | Когда разрешён пропуск задания и как он влияет на результат? |
| OQ-02 | Сколько и каких кодов необходимо для завершения задания? |
| OQ-04 | Как учитывать бонусные коды при подсчёте результата? |
| OQ-05 | Что считать доказательством корректности журнала при полном контроле клиентского устройства игроком? |

## Не относится к бизнес-правилам

- Способ шифрования, формат файлов, внутренние структуры данных и UI — проектные/технические решения.
- Работа полностью офлайн и одно устройство на команду — ограничения продукта (см. Vision & Scope).
